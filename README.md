Assignment 2 - Hypothesis Write-Up

For this assignment, I wanted to see if there were any noticeable differences in weekly income across different occupations. My hypothesis was that the type of job someone has influences their average weekly earnings. The null hypothesis stated that there would be no difference in mean income between occupations, while the alternative hypothesis suggested that at least one occupation’s average income would be significantly different from the others. To test this, I used a one-way ANOVA in R, using occupation as the categorical variable and weekly income as the numerical variable.

After cleaning the dataset and running the analysis, the output showed clear numerical differences between occupations. For example, Accountants and Auditors had higher reported weekly incomes compared to Actors and other job categories. However, when I ran the ANOVA and the Tukey post-hoc test, R returned “NaN” values for the confidence intervals and p-values. This indicates that there wasn’t enough data within each occupation group to properly calculate statistical significance. Essentially, because the dataset only included one average income value per occupation, rather than multiple observations or individual income records—there was no within-group variability for R to analyze. Without variation inside each group, ANOVA and post-hoc tests can’t produce valid results.

Even though the results weren’t statistically meaningful, they still highlight general trends in income differences across professions. The findings show how some occupations consistently report higher average earnings, which reflects real-world wage disparities between industries. The main limitation here is the dataset itself; it summarizes income at the group level rather than the individual level. If I had access to data showing individual salaries by occupation, the same test would have provided actual p-values and confidence intervals to confirm whether those differences were statistically significant.

This experience reminded me how important it is to understand the structure of a dataset before choosing a hypothesis test. Statistical tools like ANOVA only work properly when there’s enough variability and sample size within groups. In this case, the analysis was more descriptive than inferential, but it still helped me interpret income data and understand why some datasets can’t always support the tests we want to run. If I were to continue this project, I’d use a dataset with individual-level income records—so I could truly test whether income differences between occupations are statistically significant.
